## What was done

1. **#1114 (diagnosed as an ARM64 JIT / `critical()` bug)** was a compiler
   dead-store bug. `DeadStoreEdit` never examined instruction 0, so
   `n := 0;` as a method's first statement leaked one operand onto the
   interpreter's stack. It reproduced on x64 once the threaded half of the
   test was cut away. Fixed in #1116. Found along the way: #1117, where
   `return` inside `critical` never unlocks.
2. **Rosetta batch 3:** 50 tasks picked by subsystem reach from the rendered
   *Tasks not implemented in Objeck* page (#1169). Each test runs in three
   modes. The batch is recorded in `docs/ROSETTA_HARDENING.md`.
3. **Nine compiler defects** the batch found, all crash or wrong-value in
   every mode, are fixed in #1168. The PR body has the table.
4. **About 45 more findings** are filed as #1170-#1186 (below).

## Lessons that cost time today (read before changing the compiler)

- **After any `core/compiler` change, rebuild every library and explain every
  changed `.obl`.** The regression suite compiles only tests, against the
  committed `.obl` files. #1168 passed 434/434 locally and failed every CI leg
  because `gen_collect.obs` no longer compiled. The recipe:
  1. `git checkout -- core/lib`.
  2. On Windows, run `update_version.sh` through WSL:
     `wsl -d Ubuntu -- bash -c 'cd /mnt/c/.../core/compiler && bash update_version.sh'`.
  3. Check that no `file:(line,col):` error appears and that no `.obl` is
     stale: `find core/lib -name '*.obl' -mmin +15`.
  4. Diff old vs new bytecode by method for each changed library (`obc -asm`,
     split on `Method:`). `gen_collect` builds with `-lib ../lib/lang`, as in
     `build_libs.sh`.
  5. Commit the changed `.obl` files.
- **Test in three modes:** default, `OBJECK_JIT_THRESHOLD=1`, and
  `OBJECK_JIT_DISABLE=1`. Several findings exist in only one of them.
- **An "ARM64-only" failure can be an interpreter stack leak.** Run it with the
  JIT off, then at `-opt s0` vs `s1` locally, and diff the `-asm` listings.
  That cracked #1114 in minutes, after a one-leg probe PR showed the JIT was
  not involved.
- **Rosetta picks come from the rendered page.**
  `https://rosettacode.org/wiki/Tasks_not_implemented_in_Objeck`: its wikitext
  is only a template. Claim each task with a `rosetta: <Task>` issue first, as
  ROSETTA_HARDENING.md describes.
- **The full suite against a modified compiler** without disturbing
  `deploy-x64`: copy it to `core/release/deploy-x64t`, drop in the new `obc.exe`
  (and rebuilt `.obl` files), and run `run_regression.cmd x64t`. The copy is
  ~4.7 GB and not git-ignored; delete it afterwards.
- **`gh pr merge --auto` merges immediately** on this repository; merge by hand
  once checks are green.
