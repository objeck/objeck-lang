Community

Security problems: do not open an issue; follow SECURITY.md.

Talk

  • Discussions: questions and ideas
  • Issues: bugs and requests (templates provided; a small failing program helps most)
  • Rosetta Code: add a solution

Contribute

CONTRIBUTING.md has the detail. In short: branch off master, keep the change focused, say what changed and which platforms you tested, never commit credentials.

Start with the architecture map and adding an intrinsic.

Build and test

  • CI is the authoritative recipe: ci-build.yml and setup-objeck-deps.
  • Regression suite: programs/regression. ./run_regression.sh x64 (or arm64) on Linux and macOS, run_regression.cmd x64 on Windows.
  • New library: add one line to LIBS in tools/docs/guides_to_html.py; the generator fails until you do.
