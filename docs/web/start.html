Get started

Install, write a program, run it. Or use the playground: no install, libraries chosen from your use lines, no network access in the sandbox.

Install

Current release: v2026.11.4. All files are on the releases page.

PlatformDownloadNeeds
Windows x64, ARM64.msi or .zipnothing
macOS Apple silicon.pkg, .tgz or .zipnothing
Ubuntu 22.04+, Debian 12+ x64, ARM64.debnothing
Other Linux x64, ARM64.tgzglibc 2.28+

Ubuntu and Debian:

curl -LO https://github.com/objeck/objeck-lang/releases/download/v2026.11.4/objeck-ubuntu24.04-x64_2026.11.4.deb
sudo apt install ./objeck-ubuntu24.04-x64_2026.11.4.deb

Other Linux:

tar xzf objeck-linux-x64_2026.11.4.tgz
source ./objeck-lang/env.sh       # sets PATH and OBJECK_LIB_PATH
./objeck-lang/install_deps.sh     # optional: SDL2, OpenCV windows, ODBC, LAME

The Linux release runs on Ubuntu 22.04 and later, Debian 12 and later, Fedora, Arch and RHEL 8 and its rebuilds. This starts with v2026.11.4; earlier releases run on Ubuntu 24.04 only (see the README).

First program

class Hello {
  function : Main(args : String[]) ~ Nil {
    "Hello, Objeck"->PrintLine();
  }
}

$ obc -src hello.obs
$ obr hello.obe
Hello, Objeck

Libraries are named at compile time, for example obc -src app.obs -lib json,net. See Libraries.
