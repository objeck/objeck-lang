Getting-started guides

Short, task-oriented guides, each built around a complete program you can compile and run. The programs are in programs/examples/guides/; every one was compiled and run, and the output printed in a guide is what it printed. If you have not yet written a first program, start with the Quick Start, then the 32 numbered examples in programs/deploy that ship with every release.

The seven readme_*.obs programs are the short examples shown in the project README: readme_tour, readme_query, readme_json, readme_regex, readme_collections, readme_http and readme_ai.

Each file opens with a comment giving its exact compile and run lines. To build one:

cd programs/examples/guides
obc -src collections_tour.obs
obr collections_tour.obe

obc does not pull in a library's own dependencies, which is why a -lib list can name libraries the program never uses directly.

Keeping the site in step

The site pages guides.html and guide_*.html in docs/web are rendered from the Markdown in this folder, so edit the Markdown and run

python tools/docs/guides_to_html.py          write the pages
python tools/docs/guides_to_html.py --check  fail if a page is out of date

When you change a program, run it again and paste its new output into the guide that shows it.
